安装步骤¶

准备工作¶

  1. 打开包装，核对配件清单

  2. 准备螺丝刀和电工胶带

  3. 关闭电源总闸

安装流程¶

步骤说明：

  1. 将设备固定在墙面

  2. 连接电源线

  3. 打开电源，等待指示灯变绿

  4. 在手机app中完成配网
